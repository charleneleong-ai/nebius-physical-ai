Autopilot

The self-improving half of Preflight. Preflight decides whether the SO-101 robot should act; Autopilot learns from what fails. Each cycle reads the served GR00T N1.7 policy's benchmark, finds the generalisation axis (new objects, tasks or environments) with the most failures a tested recipe could fix, trains it, and lets a paired gate decide. Nemotron on Nebius Token Factory proposes; it never scores its own result.

Architecture: the agentic loop

An agent proposes; code decides. The only free choice the agent makes is which tested recipe runs next; everything that could flatter a result (the benchmark, the gate, promotion) is outside its reach.

{{DEMOS}}

Requests from Preflight

Every scene Preflight would not clear is filed here as a learning request (npai autopilot intake). Recipes that answer one rank first. A refusal caused by an untrustworthy twin is a perception problem: it is recorded as unmet, not turned into training.

Cycles

{{CYCLES}}

The menu, ranked

Reach: failed rehearsals on a recipe's axes that fail the way it addresses. Nemotron chooses among the top three eligible; families every past attempt of which was discarded are closed.

{{MENU}}

Rules the loop can't break

  • One change per cycle, so every gain is attributable.
  • A fixed menu of tested scripts; the agent can't write or run anything else.
  • The gate is code (paired McNemar on the same scenes), not the agent. G3 counts gains on suites the recipe did not train on, and fails if any suite gets worse.
  • Closed families are never revisited: {{CLOSED}}.
  • Promotion needs a human. GPU use waits for free memory, so other jobs on the host are never displaced.
